# Cabinet Door Builder

A free cut list calculator for five-piece shaker cabinet doors with a flat panel.

**Use it:** https://nagellams.github.io/cabinet-door-builder/

Type the cabinet opening and it gives you the finished door, the stiles, rails and panel, a 3D view and a to-scale drawing. You can add several doors to a job and copy the whole cut list. The door rules can be changed on the page. Doors and rules are saved in your own browser only.

The whole app is `index.html`. It loads Three.js from cdnjs and its fonts from Google Fonts.
